# 🏎️ F1 Data Analysis & Race Simulation

Projeto pessoal de engenharia e análise de dados focado em modelar o desempenho da Fórmula 1 para simulações de corrida e avaliação de valor em apostas esportivas.

## 🎯 Objetivos
- Analisar o ritmo real de corrida (*race pace*) isolando o efeito de tráfego, safety cars e paradas nos boxes.
- Desenvolver métricas de consistência e degradação de pneus por piloto/equipe.
- Construir simulações para prever probabilidades de resultados.
- Comparar as probabilidades do modelo com as *odds* de mercado para identificar apostas de valor (*Expected Value*).

## 🛠️ Stack Tecnológica
- **Python**: Linguagem principal.
- **FastF1**: Extração de telemetria e dados oficiais de cronometragem.
- **Pandas / NumPy**: Manipulação e tratamento de dados.
